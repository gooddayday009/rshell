# RShell

使用 Rust 开发的 Windows 原生 SSH 桌面客户端。界面使用 egui/eframe，终端模型使用 alacritty_terminal，SSH 使用 russh + Tokio。

## JumpServer 堡垒机（2.0.0）

从「选项 → JumpServer 堡垒机配置」填写实例名称、Web / API 根地址、KoKo SSH 主机及端口、用户名和密码，点击「登录并同步」。启用 MFA 时，自动弹出独立验证窗口并聚焦验证码输入框，可回车验证或取消本次认证。配置按连接、登录和资产同步分区，默认连接账号在可折叠区域内设置。登录成功后选择组织，授权资产自动加载到会话管理器的 `JumpServer` 目录；双击资产通过 KoKo 打开 RShell 原生 SSH 终端。资产授权、协议和账号在连接时重新检查，不会在中转失败后改为直连目标 IP。

- **登录保持**：默认 480 分钟，可设置 1–43200 分钟；实际期限取本地设置与服务端令牌有效期的较短值。勾选“记住登录状态”后，将登录令牌及绝对截止时间保存在 Windows 凭据管理器，重启不会重新计算保持时间。延长设置须重新登录；缩短设置立即限制现有登录期限。密码、MFA 验证码和单次 SSH 凭证不持久化。
- **默认账号**：登录后展开默认连接账号，点击「加载 / 刷新授权账号」，从当前组织汇总去重的授权用户名或账号别名中选择一级、二级、三级全局默认值，再保存配置，无需选择资产。每级可选「不指定」，旧配置值仍保留。加载在后台执行，可取消，整体超时 180 秒；失败不展示部分结果。连接时依次在目标资产当前有效授权账号中精确查找。单个账号直接使用；多个账号无匹配或有歧义时，需用户明确选择。没有隐式 root 优先规则；只有用户明确配置 root 且当前授权匹配时才可自动选择。需要手动输入账号或密码时仍会弹窗。
- **刷新与缓存**：登录后立即同步，默认每 60 分钟刷新，可在配置窗口调整为 1–43200 分钟，保存后重新计时，也可手动刷新。分页全部成功后才替换缓存；失败保留旧列表并提示。退出登录清除本地认证与列表，已有终端可单独断开。
- **HTTP 部署**：优先配置 HTTPS；只有明确勾选“允许 HTTP”后才使用明文 HTTP。Web 端口与 SSH 端口分别配置。HTTPS 校验证书，KoKo 主机密钥变化会阻断连接。
- **范围**：实现账号密码、MFA 验证码、登录审批状态检查、授权列表和 SSH 临时连接令牌流程。资产审批或人脸策略返回明确提示，不绕过。SSO、其他资产协议、JumpServer SFTP、sz/rz 尚未验收；JumpServer 会话暂不开放 SFTP 和 ZMODEM 文件选择。近期连接与复制/重连重新申请临时凭证。

接口依据为 JumpServer 与 KoKo 的 `v4.10.2` 标签源码；回环 API 模拟测试不代表真实部署兼容通过。完整设计及待验证范围见 [JumpServer 集成方案](docs/JumpServer集成方案.md)。

## 1. 本地直接运行

在 Windows PowerShell 中进入项目目录：

```powershell
Set-Location D:\work\rshell
rustc --version
cargo --version
cargo run --locked -p rshell
```

首次运行会下载依赖并编译，完成后打开 RShell 原生窗口，主区域默认启动真实的 Windows PowerShell（ConPTY）。可直接输入 `ssh root@主机`、`ssh -p 2222 demo@127.0.0.1` 或其他本地命令；「文件 → 本地 PowerShell」、工具栏本地终端图标或标签栏「+」可再开标签。首次打开其他会话并开始连接时，启动时自动创建的 PowerShell 标签会关闭；手动新建的本地标签不受影响。需要 Windows 10 1809 / Windows 11 或更新系统。命令行 SSH 使用系统 OpenSSH 客户端，先以 `ssh -V` 检查是否安装。退出窗口后命令结束。这里的 `rshell` 是桌面程序的 Cargo 包名，不是另外安装的命令。

本机开发已使用 Rust/Cargo **1.98.1**、`x86_64-pc-windows-msvc`。新机器需要 Rust MSVC 工具链、MSVC C++ 构建工具与 Windows SDK；安装依据见 [Rust 官方 Windows MSVC 说明](https://rust-lang.github.io/rustup/installation/windows-msvc.html)。应用代码仍然全部使用 Rust，MSVC 是链接和依赖编译工具。

没有服务器时，先看本地终端演示：

```powershell
cargo run --locked -p rshell -- --demo
```

`--demo` 只展示本地测试数据，不会自动连接任何服务器。

在「设置 → 外观与终端」可选界面字体（Geist / 系统中文字体）、界面字号（10–22）、界面缩放（75%–150%）和配色主题；主题提供 RShell 默认、dbx 风格预设及自定义背景、文字、强调色、边框、侧栏颜色，明暗模式独立切换。修改自动保存，新配置默认 VS Code 深色；已有明确保存的主题与明暗选择保留，缺少配色字段时使用 VS Code。缩放作用于整个窗口，包括终端，界面字号不改变终端字号；系统中文字体缺失时回退 Geist。该页还可独立设置终端字体、字号和主题，并查看配色预览。本地 PowerShell 与内置远端终端共用终端设置。默认 Geist Mono 与 XTerm 保留旧配置外观；Fira Code、JetBrains Mono、Cascadia Code、Consolas 仅在本机字体文件可用时可选，跨电脑缺失时回退 Geist Mono。终端主题参考 dbx 的命名与编辑器配色，针对终端适配默认色和 ANSI 16 色；远端显式真彩色保留原样，ANSI 256 色扩展继续使用 XTerm 色表。

## 2. 推荐的隔离开发方式

仓库提供 Windows 开发脚本。以下命令可以从项目根目录执行：

```powershell
# 使用 target\local-config 保存本次开发的会话和偏好
.\scripts\dev.ps1

# 隔离配置 + 本地终端演示
.\scripts\dev.ps1 -Demo

# 自动启动窗口，约 6 秒后退出，并保存实际渲染截图
.\scripts\test.ps1 -Smoke
```

若 PowerShell 的执行策略阻止脚本，不必修改系统设置，直接使用第 1、4 节的 Cargo 命令即可。

## 3. 不用真实服务器，也能测试 SSH 连接

先在一个 PowerShell 窗口启动仓库自带的**本机 SSH 测试服务**：

```powershell
cargo run --locked -p rshell-core --example local_ssh_server
```

另开一个 PowerShell 窗口启动客户端：

```powershell
.\scripts\dev.ps1
```

在客户端点击「新建会话」，填写：

| 字段 | 测试值 |
| --- | --- |
| 名称 | 本机 SSH 测试 |
| 主机 | `127.0.0.1` |
| 端口 | `2222` |
| 用户名 | `demo` |
| 认证 | 密码 |
| 密码 | `rshell-demo` |

点击「保存并连接」，首次连接会自动记录测试服务的主机密钥并继续。可在「设置 → 已信任的 SSH 主机」查看 SHA-256 指纹，并与测试服务输出对照。连接后输入 `help`、`colors`、`clear` 或 `exit` 测试终端。

这是只监听 `127.0.0.1` 的测试服务，不执行 Windows/Linux 系统命令；以上密码只是公开的测试数据。按服务端 PowerShell 窗口的 Ctrl+C 停止服务。详细行为与端口冲突处理见 [Windows 本地测试指南](docs/LOCAL_TESTING.md)。

连接你自己的服务器时，替换主机、端口、用户名和认证信息；先使用测试环境。首次连接不要求指纹确认，若需独立核验，可在连接后从可信渠道取得指纹并与已保存记录对照。私钥认证可点击「浏览…」选择本机私钥，加密私钥需填写口令。密码默认隐藏，可切换显示；在密码框按 Enter 可仅连接。

本地终端内的 `ssh` 使用系统 OpenSSH 自己的认证及 `%USERPROFILE%\.ssh\known_hosts`；「新建会话」使用应用内置 SSH 和应用自己的主机记录，两者不共享保存的密码或信任记录。

连接中或断开后，终端上方显示当前阶段或失败原因，窗口底部同时保留状态。连接失败可点击「重新连接」检查配置并重试。

### Xshell 导入与 Telnet

- 「文件 → 导入/导出 → 导出 RShell 会话 (.rsh)…」先选择一个已保存会话，也可在左侧会话上右键选择「导出会话 (.rsh)…」；「文件 → 导入/导出 → 导入 RShell 会话 (.rsh)…」可重新导入，生成新的会话 ID，放在「所有会话」，不覆盖现有配置。`.rsh` 是带格式版本的 UTF-8 JSON 文件，保存协议、名称、连接地址、串口参数和保活设置；不保存密码、私钥路径、凭据状态、文件夹 ID 或主机信任。私钥会话导出为需要重新配置认证的密码模式。导出不覆盖同名文件。
- 「文件 → 导入/导出 → 导出给 Xshell (.xts)…」先选择一个已保存的 SSH/Telnet 会话，也可在左侧对应会话上右键选择；导出单个 Xshell ZIP 会话包，包含 UTF-16 `.xsh` 基本连接字段；不含密码、私钥、主机信任、保活或文件夹。串口会话暂不能导出为 XTS。已用 RShell 的 XTS 导入器回读验证，尚待 Xshell 客户端实际导入验收。

- 「文件 → 导入/导出 → 导入 Xshell 会话 (.xts)…」选择导出文件，也可粘贴文件路径，再点击「导入配置和文件夹」。解析和保存均在后台执行。
- 已导入中文乱码时，选择同一份原 XTS，点击「修复已导入名称（不新增会话）」。只修复原导入目录中匹配原名称/路径和连接地址的文件夹、会话名称，保留 UUID、已填写用户名、连接参数和密码；不调用凭据后端。已手动改名、移动、修改地址或重命名导入根目录的条目可能不匹配；同级名称冲突时整次修复取消，原配置不变。保存沿用配置备份机制。
- 导入 SSH/Telnet 的名称、主机、端口、用户名和文件夹层级（含空文件夹）。结果放在新的「Xshell 导入」根目录；重复导入使用编号目录，不覆盖或去重已有会话。
- 密码、私钥、脚本、代理、转发、外观、保活和主机信任不迁移。SSH 默认使用密码认证，密码重新输入；私钥用户需在会话设置中重新选择认证方式和私钥。缺少用户名的 SSH 会话保留为空，连接前需补填；首次 SSH 连接会自动记录主机密钥。
- 当前读取 ZIP 格式 XTS 中 `Xshell/`（或 `Xshell/Sessions/`）下的 UTF-8/UTF-16 `.xsh` 内容；文件名支持 UTF-8 和中文 Windows 导出的 GBK，保留 ZIP Unicode 扩展字段，不再使用 CP437 默认解释中文路径。串口数字枚举参数尚未兼容，其他协议和无效会话也会跳过，结果显示分类数量。文件上限 64 MiB、4096 个条目，单会话 1 MiB、会话解压总量 32 MiB；不解压附带脚本或密钥到磁盘。
- 「新建会话」可选 Telnet，默认端口 23。**Telnet 不加密**，连接后在终端手动输入账号、密码；配置中的用户名仅作备注，不自动发送、不保存登录密码。支持字符模式、IAC 协商、终端类型和窗口尺寸协商；没有 SSH 主机校验、SFTP、跳板机或本地行编辑支持，需要服务端提供回显。真实设备兼容性仍待验收。

## 4. 自动化测试

```powershell
# 格式、严格 Clippy 检查、全部默认测试
.\scripts\test.ps1

# 检查 RShell 加密凭据文件和原生窗口
.\scripts\test.ps1 -WithCredentials -Smoke
```

等价的基础命令：

```powershell
cargo fmt --all -- --check
cargo clippy --locked --workspace --all-targets -- -D warnings
cargo test --locked --workspace --all-targets
```

SSH 集成测试会自行创建仅监听回环地址的临时服务，**不需要你提供服务器、账号、Docker 或 WSL**。它覆盖密码/加密私钥认证、主机校验、中文数据、尺寸同步、10 会话隔离和 100 轮连接释放。

加密凭据测试只在 `target/credential-tests/` 的临时目录中读写，默认测试已包含；`-WithCredentials` 可单独再执行该专项。`-Smoke` 会构建程序、启动真实窗口、自动退出，并生成 `target\test-artifacts\smoke-demo.png` 和 `smoke-local.png`。测试详情和局限见 [测试指南](docs/LOCAL_TESTING.md)。

## 5. 构建 Windows 可执行文件

### 1.3.2 Windows x64 安装包

在 Windows MSVC 构建机上安装 [NSIS](https://nsis.sourceforge.io/Download)（或提供 `makensis.exe` 路径），然后运行：

```powershell
.\scripts\test.ps1 -Smoke
.\scripts\build-installer.ps1 -MakensisPath 'C:\Program Files (x86)\NSIS\Bin\makensis.exe'
```

生成 `dist\RShell-2.3.3-windows-x64-setup.exe` 和同名 `.sha256`。安装器按当前用户安装到 `%LOCALAPPDATA%\Programs\RShell`，创建开始菜单快捷方式，可选桌面快捷方式；从 Windows“已安装的应用”卸载。升级时先退出正在运行的 RShell，再运行新安装包。卸载不删除用户配置和加密凭据。会话设置中的主机、用户名等文本可选中后按 Ctrl+C 复制，密码或私钥口令可点击字段右侧「复制」。安装包尚未签名，干净 Windows 环境、真实 Linux/OpenSSH、IME、全屏应用及长期稳定性验收仍待完成，见 [开发状态](docs/STATUS.md)。

```powershell
.\scripts\build.ps1
```

输出：`target\release\rshell.exe`。也可以直接执行：

```powershell
cargo build --locked --release -p rshell
.\target\release\rshell.exe
```

生成本地 ZIP 测试包：

```powershell
.\scripts\build.ps1 -Package
```

若旧程序正在运行导致 exe 无法覆盖，可保留原窗口并执行 `.\scripts\build.ps1 -Package -TargetDirectory target/windows-next`。此时新版程序输出到 `target/windows-next/release/rshell.exe`。

产物位于 `dist\`，包含程序、README 和相关说明，并生成 SHA-256 文件。这是便携测试包，**不是 MSI 安装包，也不是已签名发布版本**。详见 [Windows 打包说明](packaging/windows/README.md)。

## 7. 配置、凭据和常用操作

- 默认配置目录由 Windows 用户目录确定，可在客户端「设置」中查看准确路径。
- 设置 `RSHELL_CONFIG_DIR` 可以改用指定目录；同一目录只允许一个实例。
- `config.json` 保存会话、主机指纹和偏好；`config.json.bak` 保留上一份有效保存前的内容。
- 新建 SSH 会话默认勾选「记住密码 / 口令，下次连接自动登录」；可在「选项 → 设置 → 会话」关闭或重新开启这个新建默认值，已有会话不受影响。勾选后按 Enter、「保存会话」或「保存并连接」会加密保存凭据；「仅连接」不保存，也可在会话中取消勾选。以后点击保存会话、最近连接或快捷栏会自动读取凭据并连接，右键会话 →「编辑会话」可修改或取消记住。凭据缺失或读取失败会留在设置窗口提示重新输入。首次主机密钥自动保存；已记录密钥变化时仍阻断连接。
- 密码和口令保存在配置目录的 `credentials/<会话 UUID>.bin`，使用当前 Windows 用户的 DPAPI 加密并绑定会话 UUID；JSON 中没有密码。不再使用 Windows 凭据管理器，也不迁移其中的旧密码，升级后需重新输入一次并保存。加密文件不可作为跨用户或跨机器的便携密码备份。
- 鼠标拖动选择文本，松开后默认自动复制；也可使用「复制选区」或 Ctrl+Shift+C；Ctrl+C 发送终端中断。Ctrl+V 粘贴默认删除尾部换行、空格和制表符等空白，保留开头及中间内容，清理后仍含多行时需确认。粘贴时会过滤不可见控制字符（保留换行和 Tab），单独的回车按换行处理；需要发送 Ctrl+C 等控制键时请直接按键。
- 「选项 → 设置 → 外观与终端 → 复制与粘贴」可分别关闭上述两项默认行为，设置自动保存；旧配置缺少这两项时默认开启。终端采用实心光标，选区与文字使用同一字体行高，拖选按最近字符边界定位。
- Shift+PageUp/PageDown 或鼠标滚轮查看历史；Shift+鼠标强制文本选择；查找覆盖当前终端保留的历史。
- 终端右侧竖向滚动条可拖动回看历史；终端内容区右键菜单提供复制、粘贴和添加选中内容到 AI 对话；选择「粘贴」后粘贴剪贴板文本，使用与 Ctrl+V 相同的过滤和多行确认规则。远端程序启用鼠标报告时，右键仍交给远端程序。
- 关闭标签会断开该连接；删除会话配置不关闭已经运行的连接；重新连接会创建新的远程 shell，不重放命令。

在「选项 → 设置 → 快捷键」点击键位后按新的组合键，可配置新建本地标签、关闭标签、前后切换标签（含备用键位）、复制终端选区和查找终端内容。查找默认 `Ctrl+Shift+F`，Ctrl+F 交给 Shell 向右移动。加载旧配置时自动迁移原 Ctrl+F 查找；若新键位已被其他动作占用则保留并由用户解决冲突。其他自定义键位保留，可单独修改或恢复默认。录入从原始按键事件读取，避免控件先处理按键后录入无反应。键位修改自动保存到 `config.json`；重复键位和未含 Ctrl/Alt 的键位不接受，Esc 取消录入，也可恢复全部默认键位。终端的 Ctrl+C 中断、Ctrl+V 粘贴、Shift+PageUp/PageDown 回看仍为固定操作。快捷键仅在设置与其他弹窗关闭后作用于终端或标签。其他缺口见 [开发状态](docs/STATUS.md)。

常用终端按键见 [快捷键说明](docs/SHORTCUTS.md)。新增 Ctrl+Tab / Ctrl+Shift+Tab 切换标签、Ctrl+Shift+V 粘贴、Ctrl+Shift+A 清除本地显示与历史、Shift+Home/End 跳到历史顶部/底部、Shift+↑/↓ 逐行滚动。Ctrl+A/E 等控制键发送给当前 Shell；输入法组合期间切换焦点后会清除旧组合状态，避免控制键被残留状态拦截。真实 SSH 下的实际动作取决于 Shell 键位、tmux/screen 和远端应用。


## 主机信任管理

在「设置 → 已信任的 SSH 主机」查看内置 SSH 的主机、端口、算法、指纹和记录时间。点击「核验 / 更新 / 移除…」后，可粘贴从可信管理渠道取得的 OpenSSH 主机公钥，并输入独立核验的 SHA-256 指纹。两者匹配、确认核验后才允许保存；更新后需重新连接。删除会使下次连接重新自动记录该主机密钥，不会断开已有连接。

## 标签右键菜单

标签高度收紧，单个标签宽度为 84–140 逻辑像素，并随窗口宽度自动收窄；长名称以省略号显示，悬停可看完整名称。标签太多时，鼠标位于标签标题区域可用滚轮左右滑动标签栏，不改变当前标签；也可用标签栏两侧的「◀」「▶」按钮或 Ctrl+PageUp / Ctrl+PageDown、Ctrl+Alt+← / Ctrl+Alt+→ 切换相邻标签，到末尾后从另一端继续。切换后当前标签会自动滚入可视区域，普通方向键仍发送给终端。

右键点击标签标题可新建选项卡（本地 PowerShell，Shift+Alt+N）、复制会话、复制 SSH 渠道、清屏、关闭当前/右侧/所有本地/断开的连接/其他/全部标签，以及重命名。清屏只清除所点标签的本地显示和滚动历史，不向连接发送命令。Ctrl+Shift+F4 关闭当前标签。

- 复制会话：本地标签新开 PowerShell；内置 SSH 使用原会话配置建立新连接，保存凭据时沿用原自动登录流程，否则需重新输入认证信息。
- 复制 SSH 渠道：仅已连接的内置 SSH 标签可用，复用原已认证连接打开独立 PTY/shell，无需重新输入密码。输入、输出、窗口尺寸独立；关闭其中一个标签不关闭其他渠道，最后一个渠道结束后释放 SSH 连接。服务端必须允许多渠道，拒绝时在新标签显示错误。
- 重命名：仅修改当前标签标题，不修改保存会话，也不持久化；名称不能为空，最多 128 字符。
- 批量关闭按右键所点标签的位置执行；“本地”指 PowerShell 标签，包括其中手工启动的系统 ssh。关闭会结束相应终端；不会删除保存的会话。
- 「关闭断开的连接」会关闭所有已经结束或连接失败的远端标签；正在连接、已连接以及本地 PowerShell 标签会保留。没有符合条件的标签时，此项不可点击。
- 当前没有选项卡组，“关闭此选项卡组”保持禁用；左侧会话文件夹不等同于选项卡组。

## 会话文件夹

在「选项 → 设置 → 会话」可设置退出和终止会话前确认、远端连接结束后在同一标签启动本地 PowerShell、连接关闭时清除该标签的回看、已保存会话点击「连接（自动保存）」时保存非凭据设置，以及新建 SSH 会话是否默认勾选记住密码 / 口令。修改登录目标或凭据时仍需使用「保存并连接」。单窗口多会话已由标签页提供，设置中显示为固定启用。默认依次为开启、开启、开启、关闭、开启、开启；旧配置缺少新开关时也默认开启。


会话管理器以「所有会话」为根显示可折叠的文件夹树，支持最多 32 层。点击会话管理器顶部的文件夹加号图标创建顶层目录；右键文件夹可新建子文件夹、在该目录新建会话、重命名或调整父文件夹。空文件夹会独立保存，非空文件夹禁止删除，需先移动其中的会话和子文件夹。

会话设置中的「文件夹」下拉框指定保存位置；右键已有会话 →「移动到文件夹」可以直接移动，不改动凭据和已打开连接。「所有会话」表示根目录。搜索名称、主机或文件夹路径时自动展开匹配分支，保留父级路径；清空搜索后恢复原折叠状态。

也可把会话行拖到目标文件夹，或拖到「所有会话」移回根目录；文件夹右侧的「⋮⋮」是拖动柄，可拖到其他文件夹或根目录。无效的循环嵌套不会接受投放。会话还可直接拖到顶部快捷连接栏添加快捷入口；重复拖入不会重复添加。搜索框右侧的「×」可一键清除搜索。

旧配置中的每个非空分组原样迁移为顶层文件夹（名称中的斜杠不拆分），空分组会话放在根目录；会话 ID、凭据关联和主机信任不变。迁移读取不覆盖原文件，下次保存时写入 schema 4 并按原机制保留备份。旧版程序不能读取 schema 4。

## AI 配置

### 内置 Agent（Claude Agent SDK）

AI 面板默认是 **Agent · 通用问答**。底部模式菜单顶部可切换 **Ask / Agent**，Agent 下有「通用问答」「命令建议」「会执行（谨慎选择）」；启动不会自动进入执行模式。Ask 直接问答，不自动附带终端视口；Agent 的前两项可附带有限终端上下文，只回答或生成建议，不调用执行工具；代码块的「执行」可由用户点击，逐次确认后手动发送到终端。「会执行」使用官方 Claude Agent SDK 的推理与工具调用循环，通过 RShell 的受限 MCP 桥接已连接的 PowerShell/SSH 终端，每条命令仍需人工确认。完整应用目录包含 SDK、Python 运行时及配套引擎，用户无需单独安装 Python 或 CLI。

- 模型、地址和密钥统一使用「设置 → AI」的完整模型配置；底部选择配置后按 UUID 同时切换三项，即使两个配置的模型名称相同也不会混用。新增「接口类型」：OpenAI Chat Completions、Anthropic Messages。旧配置默认保留 OpenAI 格式；两种接口均可用于问答与命令建议，「会执行」只接受 Anthropic Messages 配置。改选接口类型不会转换供应商协议，需填写供应商实际提供的对应地址。
- Anthropic 基础地址可带末尾 `/v1`，应用统一规范为根路径后访问 `/v1/messages`；自定义路径前缀保留。SDK 使用所选配置的 `ANTHROPIC_BASE_URL`、API Key 与模型，不再继承其他 Claude 用户配置中的认证、模型别名或云供应商选择。密钥由后台从现有 DPAPI 存储读取，只传入子进程环境，不写入 JSON、桥接请求或命令行。缺失密钥、接口不兼容或读取期间切换会话时停止本次请求。
- 「设置 → AI → Agent 设置」只设置 SDK 组件路径及最大轮次（默认 10，范围 1–30）。路径留空优先复用应用旁的离线组件，否则使用当前用户缓存，缺少组件时弹框，由用户选择从公开 GitHub Release 下载或使用本机组件；历史独立模型字段不再用于界面请求。模型配置在运行中不能从侧栏切换。输入区右上角为小字号「当前窗口信息」开关；悬停圆形帮助图标查看发送范围，并可打开终端发送内容预览。模式、模型、帮助和发送使用与 dbx 相同的 Lucide SVG 图标，发送按钮为圆形向上箭头。
- 发送范围为有限对话历史、目标身份，以及开启时的所选终端当前视口（最多 6000 字符）。可预览视口或关闭自动附带；工具读取同样遵守开关。敏感行会尽力遮盖，但不保证识别全部秘密，发送前须检查；不自动读取文件或完整终端历史。
- Agent 可读取视口或提出一条命令。命令卡片展示目标身份、完整可编辑命令、用途、影响及前提；点击「确认执行本次命令」才向该终端写入并回车。既有命令检查继续生效，不能替代人工核对。
- 发送后点击「刷新当前终端视口」，检查并编辑内容，再点击「提交以上输出并继续」。屏幕可能包含旧内容，应用不会把发送成功视为命令完成，也不推断退出码。每个后续命令重新确认。
- 切换工作区终端、更改执行目标、断开连接、新建/切换/清空对话或点击停止，会取消当前 Agent 与待执行操作。停止不会撤回或中断已经发给终端的命令。
- SDK 引擎的内置工具关闭，仅开放本次运行的 `read_terminal` / `execute_command` MCP 工具；桥接绑定回环地址和每次运行的随机令牌。模型输出不能直接执行本机操作。单次任务最多 15 分钟、每次工具等待最多 5 分钟，进程输出上限 4 MiB；SDK 错误与超时显示在面板中；停止时通过 Windows Job Object 清理整个 SDK 进程树。

开发构建先运行 `scripts/build-agent-sdk.ps1 -InstallDependencies`（需要 Python 3.10+ x64）；中间文件位于 `target`，组件复制到 `target/debug/agent-sdk`。默认发布构建不包含该目录；需要完整离线包时给构建脚本加 `-WithAgent`。SDK 桥接仅使用少量 Python，界面、终端、工具权限和会话管理仍为 Rust；这是按用户指定 SDK 方式引入的边界组件，无 Web 前端。

实现、自动化验证和真实终端人工验收分别见 [docs/STATUS.md](docs/STATUS.md)。不代表其他 SDK 版本、认证方式或远端 Shell 均已兼容。

打开「设置 → AI」，点击「新增配置」，选择接口类型并填写名称、对应协议的 API 基础地址和模型 ID。支持编辑、设为默认和确认删除；首个配置自动设为默认，删除默认项后选择列表中的首项。最多保存 100 项。

需要保存 API Key 时勾选「加密保存 API Key」，密钥使用当前 Windows 用户 DPAPI 加密，位于现有 `credentials/<配置 UUID>.bin`；JSON 和备份仅保存非密钥配置。编辑时密钥留空保留原值，取消勾选并保存会删除原密钥。配置及密钥在后台保存，失败时恢复原值。旧配置文件可直接加载。

问答和命令建议使用当前配置的 OpenAI `/chat/completions` 或 Anthropic `/v1/messages` 接口，需加密保存 API Key。Enter 发送问题、Shift+Enter 换行，也可点击「↑」；请求最多等待 60 秒，可点击「停止」取消。失败或停止时，若输入框为空则恢复原问题；若已经输入新草稿，原问题保留在对话中，新草稿不被覆盖。顶部「新对话」开始新会话，对话下拉框可切换旧会话，「历史」可打开或删除旧会话。最近 20 个对话、每个最多 20 条消息，使用当前 Windows 用户的 DPAPI 加密保存在配置目录 `ai-history.bin`。需要分析终端内容时，先在终端中选中文字，再右键选择「添加选中内容到 AI 对话」；内容会加入草稿并选择该终端作为目标，不会自动发送。输入框固定高度并支持内部滚动，最多保留 8000 字符，超出时会提示截取。OpenAI 兼容接口连接测试尚未实现；Agent 的逐次确认流程见上节。
输入区「选择连接」用于指定命令执行目标，支持已连接的本地 PowerShell 或 SSH 标签。底部模型名称可点击，快速切换已保存的默认模型。问答和命令建议模式可给出代码块，也可由用户点击「执行」进入人工确认；AI 回复中的代码可手动选中或点击「复制」。单行 `powershell`/`pwsh`（本地）、`bash`/`sh`/`shell`（SSH）及未标语言的代码块，均显示可点击的「执行」按钮，不受 Ask/Agent 模式限制；语言与目标不匹配、多行或被阻止的命令点击后显示原因，不发送到终端。点击后先显示目标和可编辑的完整命令，编辑后重新检查；仅点击「确认执行」才发送到所选终端并回车。目标断开、执行目标改变或工作区切换终端时，待执行命令会被取消。「设置 → AI → AI 命令黑名单」可额外禁止命令名，每行一个；内置高危规则不可关闭。不再因 `&&`、`;`、管道、重定向、变量或括号等 Shell 语法整体拦截单行命令。现有命令名检查以首个命令词为主，并非完整 Shell 解析器，不能覆盖组合命令内所有子命令；确认前仍需人工核对完整命令。

开发时可用 `cargo run --locked -p rshell -- --demo --ai-settings` 直接打开 AI 设置页；可与 `--smoke-test` 配合检查窗口渲染。


AI 回复采用浅灰白面板、蓝色用户消息和独立代码卡片；支持段落、列表、标题、强调文字和行内代码的基础排版。代码块提供基础词法着色、复制与命令执行确认，整条回复可复制。输入框固定高度，长内容在内部滚动；对话区和输入区的滚动条默认隐藏，鼠标移入时显示；历史对话标题单独占一行并截断显示。

AI 对话面板启动时默认关闭，打开后停靠主窗口右侧，可拖动左边界调整宽度，点击「×」收起，通过工具栏「AI 对话」或「查看 → 显示 / 隐藏 AI 对话」重新打开。面板显示默认配置，右上角「配置」打开 AI 设置。底部支持最多 8000 字的问题草稿；终端右键菜单可将选中内容加入草稿。

## SSH 保持活动状态

在「设置 → 连接 · 保持活动」中选择已保存的 SSH 会话：

- **保持活动状态消息**：默认开启，间隔 60 秒，可设置 1–86400 秒；使用 SSH 协议保活，不向 shell 输入文字。沿用 russh 的无响应断开机制（keepalive_max = 3）。
- **网络空闲时发送字符串**：默认关闭，启用后需填写 1–86400 秒及非空字符串（最多 1024 UTF-8 字节）。按 UTF-8 原样发送，不解析 `\n` 等转义，也不追加回车；字符串会进入远端终端，并明文存入会话配置，不应包含秘密。
- **TCP 保持活动数据包**：默认关闭；开启后使用操作系统默认 TCP 探测时间，与 SSH 消息间隔独立。

空闲发送根据整个 SSH TCP 连接实际收发流量计时，SSH 保活和共享渠道流量也会重置空闲时间。因此 SSH 保活间隔短于空闲字符串间隔时，字符串可能不会发送。复制渠道共用原连接的设置和空闲计时，每次空闲仅一个渠道发送字符串；需要每个终端独立发送时使用「复制会话」创建独立连接。

设置随会话保存，下次连接生效；旧配置缺少该字段时采用上述默认值（替代原固定 20 秒保活）。不控制本地 PowerShell 内运行的系统 `ssh`。

## 串口连接

打开「文件 → 新建 SSH / 串口会话」，在连接方式中选择「串口 (Serial)」。填写 COM 端口，或点击「刷新」从可用端口中选择；设置波特率、数据位、停止位、奇偶校验和流控制，再选择「保存并连接」或「仅连接」。默认参数为 COM1 / 115200 / 8 / 1 / 无校验 / 无流控制。波特率提供常用下拉值，也可手动输入；是否支持取决于设备驱动。

串口会话可保存、编辑、复制和重新打开，复用终端输入、回看与多标签。串口不需要用户名、密码或 SSH 主机指纹；窗口调整只改变本地显示尺寸。支持 5–8 数据位、1/2 停止位、None/Odd/Even 校验及 None/XON-XOFF/RTS-CTS 流控制。关闭标签释放端口；设备占用、拔出、读写失败会显示错误，不自动重发输入。真实设备通信仍需按测试指南验收。

## 设置布局

「选项 → 设置」采用左侧分类、右侧配置：外观与终端、连接 · 保持活动、SSH 主机、AI 配置。保活从会话编辑窗口移至设置，选择已保存的 SSH 会话后点击「保存保活设置」，下次连接生效；切换会话会放弃未保存修改。新建或编辑会话同样采用左右布局：左侧选择 SSH / 串口，右侧填写名称、文件夹与对应协议参数，底部保存或连接。

AI 面板采用顶部新对话/历史工具栏、可选择文本与复制代码的消息区、底部连接选择及 Ask/命令建议输入区。附件尚未接入。测试参数 `--smoke-test --smoke-ai-chat --demo` 用于检查展开面板。

设置与会话窗口使用宽松间距：20 px 内边距、34 px 控件高度、分组留白与分隔线，适用于深浅两种主题。

会话管理器缩放：把鼠标放在会话管理器内，按住 Ctrl 滚动滚轮，无需按住鼠标键。缩放范围为 75%–175%，仅影响会话管理器，并自动保存到本机配置；下次启动恢复上次比例。普通滚轮仍用于侧栏列表滚动。

界面字体使用 Geist Variable，并保留 Windows 中文字体回退；终端使用 Geist Mono Variable，以固定字符宽度绘制命令、光标和选区。字体文件来自 Vercel Geist，按 SIL Open Font License 1.1 随源码保留许可，便携包在 `licenses/Geist-OFL.txt` 中附带许可。

终端缩放：鼠标放在当前本地 PowerShell 或内置 SSH 终端内，按住 Ctrl 滚动滚轮（同时按住鼠标左键也可），向上放大、向下缩小，字号限制 10–32。只影响当前标签的终端文字与网格，不改变菜单、侧栏、其他标签或已保存的默认字号；关闭标签后恢复默认。

## SSH 文件传输（sz / rz / SFTP）

适用于 RShell 内置 SSH 会话；本地 PowerShell 中手动运行的 ssh 和串口会话不接入此功能。

- 远端执行 `sz 文件名`：检测到 ZMODEM 握手后选择本地接收目录，支持远端一次发送多个文件。
- 远端执行 `rz`：选择一个本地文件上传到远端当前目录。再次执行 `rz` 可上传下一文件；单文件必须小于 4 GiB，更大文件使用 SFTP。
- 传输中状态栏显示字节数，Esc / Ctrl+C 取消；选择对话框取消也会通知远端终止。选择窗口等待上限为 120 秒。
- 顶部「SFTP」或「工具 → SFTP 文件传输…」打开当前 SSH 会话的文件窗口，自动读取远端主目录；可输入路径、进入文件夹、返回上级、刷新、上传和下载。SFTP 路径与 shell 的 `cd` 不同步。SFTP 复用已认证的 SSH 连接，终端继续保持连接。
- SFTP 单任务流式传输，显示已传字节数；可点击取消，关闭文件窗口或 SSH 标签也会取消该任务。目录最多显示 10000 项，超限时应输入更具体路径。
- 本地下载以及 SFTP 上传不覆盖同名文件，请选择新名称或先自行处理旧文件。先写 `.rshell-UUID.part` 临时文件，成功后再发布；失败、取消或断线可能留下临时文件，可人工删除。本地发布使用同目录硬链接，目标磁盘需支持硬链接（例如 NTFS）。`rz` 接收端对远端同名文件的处理由远端 rz 参数决定。
- 来自远端的 ZMODEM 文件名只允许普通文件名，不接受绝对路径、目录穿越、Windows 设备名或附加数据流；不会执行 ZMODEM 携带的本机命令。

实现及本机协议测试已完成；真实 Linux/OpenSSH + lrzsz、原生文件选择器的完整交互、大文件长时间传输及断网恢复仍待验收。详见 [本地验证](docs/LOCAL_TESTING.md)。

### AI 对话工具与显示设置

- 顶部显示截短的当前对话标题和单排图标，图标由应用绘制，悬停显示操作名称。首个图标「新对话」保留旧对话历史；其后依次为导出 Markdown、历史、清空当前对话、展开/还原、AI 配置和收起。导出内容不包含 API Key 配置；清空会删除当前对话的消息、草稿及对应历史记录，其他历史不受影响。
- 终端连接继续保持。用户消息靠右显示，助手回复使用浅蓝内容区，代码单独成卡片；代码卡片左侧显示截短的语言标识，执行与复制操作靠右。代码与整条回复使用双页图标复制，悬停显示复制范围。底部固定输入区保留连接目标、模式、模型与发送操作；窄侧栏下模式名称缩短，模型与连接名称截断并可悬停查看完整名称，发送按钮保持可见。
- AI 设置采用模型配置卡片和独立字体卡片，可搜索设置或模型。对话默认字号 12，可选 10–24，支持跟随界面字体或等宽字体，并可一键重置。修改自动保存，作用于 AI 正文及输入框；代码保持等宽并使用相同字号，终端字号不变。


### 同一窗口分屏显示多个终端

在「窗口(W)」选择「左右分屏」「上下分屏」或「网格分屏」：左右/上下分为两屏，网格分为四屏。每屏拥有独立标签栏，可在该屏内切换会话，点击该屏的「+」新建本地 PowerShell；从会话管理器新开的连接进入当前屏。拖动标签到另一屏，或右键选择「移动到第 N 屏」，可移动会话而不断开连接。拖动屏间分隔条调整大小；Ctrl+PageUp/PageDown 在当前屏内切换标签。每屏仅显示自己的选中终端，输入只发送到当前活动屏。关闭最后一个标签后保留空屏，可继续拖入标签或新建；切回单终端显示全部标签。分组与大小仅在当前运行期间保留，切换布局会重新等分尺寸。

已验证：分屏输入隔离、屏内独立标签切换、跨屏拖动、关闭/新建分组状态、分隔条拖动和布局切换后的尺寸调整，以及 Windows 四屏八标签窗口截图。真实远端分屏操作、IME 与全屏应用仍待人工验收。

### SSH 密钥管理

从 **工具(T)** 打开 **主机密钥管理器** 或 **用户密钥管理器**。

- 主机密钥：查看主机、端口、算法和 SHA-256 指纹，通过已有独立核验流程更新或移除信任记录。移除后下次连接将按首次连接自动记录密钥，需先确认服务器身份；密钥变化仍阻断连接。
- 用户密钥：填写名称后生成 Ed25519 或 RSA（2048 / 3072 / 4096 位），也可输入源私钥口令并导入 OpenSSH / PEM 私钥。列表提供属性、公钥复制、公钥导出、私钥导出和确认删除。
- 私钥保存在配置目录的 `user-keys/*.rkey` 中，由当前 Windows 用户的 DPAPI 加密保护，不写入配置 JSON。管理器口令框用于导入解密或导出加密，不是托管密钥的登录口令。
- 选择密钥后点击“用于 SSH 会话…”，检查会话属性并保存；也可在会话私钥路径中选择 `.rkey` 文件。托管密钥无需填写登录口令。公钥仍需自行配置到服务器授权列表。
- 导出私钥必须填写保护口令，输出为加密的 OpenSSH 私钥；公钥和私钥导出均要求新文件，避免覆盖。删除需要确认，会使引用该密钥的会话下次认证失败。`.rkey` 绑定当前 Windows 用户，不作为跨机器备份；迁移请使用带口令的私钥导出。

已验证：自动化密钥生成、加密存取、导出再导入、错误口令、输入上限和回环 SSH 认证，以及两个管理窗口的单场景渲染。真实 Linux/OpenSSH、文件选择器交互和跨机器迁移仍待验收。

### 界面栏显示与终端回看

在「查看(V) → 界面栏显示」分别切换菜单栏、工具栏、地址栏、快捷栏，设置会自动保存。顶部栏全部隐藏后，仍可右键底部状态栏恢复任意一栏或点击「显示全部栏」；Ctrl+Shift+M 可切换菜单栏。

「设置 → 外观与终端 → 配置与使用说明」提供终端回看上限，默认 5000 行，可输入 0–100000 行后点击「应用」。0 表示关闭回看；保存后立即作用于所有已有终端，新建终端和重启也使用该值。调低上限会丢弃超出的旧历史；较大行数会增加内存占用，尤其是同时打开多个宽终端时。

设置中已移除重复的「SSH 主机」页面，统一从「工具 → 主机密钥管理器」进入。

### 2.3.0 轻量安装与按需 Agent 组件

默认安装包和便携包只包含主程序、文档及许可。使用「Agent · 会执行」且缺少组件时弹出选择框，提供「下载并使用」「选择本机组件…」「取消」；只有用户选择下载后才访问组件下载源。已有缓存或已配置组件直接复用。普通终端、Ask 和仅回答模式不会下载。下载进度显示在 AI 区，可点击停止取消；网络错误或校验失败后可重新发送请求重试。

组件来自公开的 `gooddayday009/rshell-components` GitHub Release，版本和 SHA-256 固定在应用内。下载和解压在后台进行，通过大小、ZIP 路径、协议与文件清单校验后才启用。缓存位置为 `%LOCALAPPDATA%\RShell\components\<组件版本>`；后续启动直接复用。卸载主程序保留此用户级缓存，旧版离线组件或明确指定的 SDK 路径仍可使用。

当前组件 ZIP 约 147 MiB，按需下载只减小默认主程序包，不减少首次 Agent 下载总量。离线环境可使用 `-WithAgent` 完整包或在「Agent 设置」指定离线组件 exe。详见 [组件交付说明](docs/AGENT_COMPONENT.md)。
