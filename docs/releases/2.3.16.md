# RShell 2.3.16

新增 Xshell 会话密码导入和 RShell 加密备份。

- XTS 导入可迁移通过摘要校验的 SSH 登录密码，优先处理 7.1/8.1；需要时输入 Xshell 主密码或来源 Windows 用户信息。支持仅导入配置和显式允许部分导入，默认解密失败整批不写入。
- `.rsh` 导出可选包含已保存登录密码，必须设置并确认独立导出口令。使用 Argon2id + AES-256-GCM 整体加密，导入时验证口令和完整性后重新保存凭据；旧 `.rsh` 仍兼容。
- 批量凭据保存失败回滚，进程中断后清理未提交凭据；主密码不持久化，密码不进入配置 JSON 或日志。`.xts` 导出仍不包含密码，私钥和私钥口令不在迁移范围内。

本机发布检查通过：278 项常规测试（串行）及 24 个窗口冒烟场景；凭据专项已复核通过。合成向量、错误口令、篡改、回滚和恢复测试已通过。用户提供的真实 XTS 已完成只读扫描，但真实主密码解密、跨电脑恢复和真实服务器登录仍需人工验收，不能由合成测试推定通过。

发布流程构建 Windows x64 安装包/便携包及 macOS arm64/x64 应用包，附 SHA-256。Windows 未签名；macOS 使用 ad-hoc 签名，未公证。真实安装升级、输入法、全屏应用、物理串口和性能验收保持开放。
