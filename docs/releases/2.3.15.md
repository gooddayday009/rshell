# RShell 2.3.15

提供 Windows x64 安装程序及便携 ZIP、macOS Apple Silicon 和 Intel 应用 ZIP，每个包附 SHA-256 校验文件。

macOS 支持本地 zsh、钥匙串保护、中文字体与 Command+C/V，隐藏 Windows 专用 Agent 执行组件，保留 AI 问答和命令建议。

本次按用户要求将版本由未正式发布的 2.3.20 调整为 2.3.15，应用代码未改变。沿用此前通过的 Windows 完整测试、凭据专项、窗口冒烟及双架构 macOS 测试证据；本次仅重新构建正确版本并校验发布包，不重复整套测试。此前 macOS CI：https://github.com/gooddayday009/rshell/actions/runs/42177646857

macOS 使用 ad-hoc 签名，未进行 Apple Developer ID 签名或公证；Windows 包未进行 Authenticode 签名。真实输入法、真实服务器兼容性、物理串口、全屏应用、性能及用户安装/升级验收仍保持开放。
