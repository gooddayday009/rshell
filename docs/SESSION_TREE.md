# 会话树排序与移动

在左侧“所有会话”中，按住文件夹或会话行拖动：

- 拖到目标行上、下边缘：插入到该行之前、之后，插入位置显示横线。文件夹和会话可以混合排列；跨目录拖动同时改变所属目录。
- 拖到文件夹中部：移入该文件夹末尾，目标文件夹显示边框。折叠的文件夹也能接收拖入，单击展开后查看。
- 拖到“所有会话”：移回顶层末尾。
- 拖动期间靠近列表上下边缘自动滚动；按 Esc 或在列表外松开取消。

文件夹使用 14 px Lucide 线框图标区分展开与收起，颜色适配深浅主题；悬停时显示拖动手柄，整行均可开始拖动。窄侧栏中的长文件夹名省略显示，悬停可查看完整名称。

排序与目录关系由后台配置服务保存，重启保留。保存失败显示现有错误提示，仍保留原目录和顺序。旧配置首次打开维持原来的文件夹优先、名称排序；手动排列后保留该顺序，新增或导入的条目排在已排列条目之后。搜索时相对目标条目插入，隐藏条目仍被保留。现有会话导出格式不包含会话树的目录与顺序。

移动文件夹会保留其子文件夹和会话，不改变会话 ID、连接信息和凭据。不能移入自身或后代目录，不能产生超过 32 层嵌套或同目录同名文件夹。拖动松开不会触发会话连接。

## 开发验证

`scripts/test.ps1` 运行核心排序、配置读写和 egui 鼠标事件回归。测试包括混合排序、跨目录移动、循环嵌套与同名冲突、搜索时排序、Esc 取消、凭据不变及磁盘写入失败回滚。

单场景原生窗口验证使用隔离配置，截图写入 `target/test-artifacts`：

```powershell
$env:RSHELL_CONFIG_DIR = "$PWD/target/test-artifacts/session-tree-config"
$env:RSHELL_SCREENSHOT = "$PWD/target/test-artifacts/session-tree-dark.png"
& ./target/debug/rshell.exe --demo --smoke-test --smoke-session-tree
```

追加 `--smoke-light` 验证浅色主题，追加 `--smoke-tree-narrow` 验证 800×520 窗口和 180 px 侧栏。参数仅用于演示数据，不连接真实服务器；请在独立测试 PowerShell 进程运行，避免环境变量影响后续正常启动。
